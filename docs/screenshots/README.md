# Screenshot folder

Recommended public screenshots:

- `01-main-window.png` — main Flight Map Tools GUI with tabs visible.
- `02-2d-map.png` — normal interactive HTML route map.
- `03-analysis-report.png` — Flight Data Analysis HTML showing both map and timeline.
- `04-google-earth-kmz.png` — 3D KMZ route in Google Earth.

Before uploading screenshots, check them for:

- private home/launch locations;
- file paths containing your Windows username or personal folder names;
- aircraft/log names you do not want public;
- browser tabs, notifications, email addresses, or other unrelated private information.

Suggested image width: roughly 1400–2000 px. PNG is a good default for UI screenshots.
